Purpose
-------

This record describes the verified architecture after removal of the historical
numbered classification and separation of generic Lean namespaces from the
circular/perimetral instance namespace. The repository is organized by
mathematical role: abstract residual determination, abstract turning, the
circular/perimetral instance, generic exact transport, generic
alignment/persistence theory, mediated-transition coherence, and an autonomous

Verified architectural trunk
----------------------------

The scientific trunk of the circularity development is:

  SegmentedResidualRole
    -> AbstractSegmentedTurning
    -> StrongPerimetralTurning

`SegmentedResidualRole` is the abstract residual-determination kernel.
`AbstractSegmentedTurning` consumes that kernel while remaining independent of
circular presentations. `StrongPerimetralTurning` is the concrete
circular/perimetral instance of the project.

`SegmentedResidualRoleStrictness` is a lateral separator/audit of the residual
kernel. It is not a productive stage between residual determination and abstract
turning.

Mediated coherence
------------------

The mediated-transition modules formalize observed commutation,
faithful/local-reflection upgrade, identity, sequential composition, and
pasting. The nonfaithful-middle regression shows that intermediate literal
commutation/faithfulness is stronger than required for observed pasting;
terminal reflection suffices to recover literal outer commutation.

The independent kernel is `MediatedTransitionCoherence`; the finite-alignment
specializations are under `Alignment`. These results remain independent of
`RepresentationBoundary`.

Scope boundary
--------------

The finite persistence result proves persistence/transport of occurrence
identity through the generated finite histories. It does not by itself prove
persistent non-admission or out-of-distribution status at every later depth.

The representation-boundary result is an abstract semantic diagonal result. It
is not upgraded here into a formal Gödel incompleteness theorem: no syntax of
formulas, arithmetization, provability predicate, or formal consistency theory
is introduced by this refactor.

Likewise, the representation-boundary result is not required for dynamic
alignment. It remains autonomous with a separately named application to
circular statuses.

This file is not itself listed in MANIFEST.sha256. This audit-only commit must
therefore be followed by the same ordinary CI validation; that final run checks
that the repository remains buildable and that the scientific manifest remains
unchanged and valid.
